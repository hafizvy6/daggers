02 · The four tags

Base hues paint dots, bars and 4px rules (non-text, ≥3:1). Tag text uses the -ink variant so small mono type clears 4.5:1 on its tint. That distinction is the whole tag rule.

05 · The contract
Always do
  • ✓ tokens only — var(--…)
  • ✓ logical properties (inline/block)
  • ✓ every string through t("ns.key")
  • ✓ LTR islands for domains & numbers
  • ✓ paper-lift on actionable cards only
  • ✓ the AI case-writer is the only show animation
Never don't
  • ✕ dark mode, neon glow, blurred shadows
  • ✕ pure black, gradients on data
  • ✕ left / right in CSS
  • ✕ raw hex outside tokens.css
  • ✕ italics in Arabic · letter-spacing in Arabic
